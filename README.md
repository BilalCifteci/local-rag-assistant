# Local RAG Assistant

Foundry Local kullanarak tamamen offline calisan, RAG (Retrieval-Augmented
Generation) mimarisine dayali bir dokuman soru-cevap asistani.

## Kurulum

```
python -m venv venv
venv\Scripts\activate
pip install foundry-local-sdk-winml
```

## Dosyalar

- `app.py` - Hafta 1: Foundry Local kurulum testi (Hello Model)
- `embed_test.py` - Hafta 2: Embedding uretimi ve cosine similarity testi

## Calistirma

```
python app.py
python embed_test.py
```
